# Vidya Vikas Academy Starter

A minimal Next.js starter for Cashfree onboarding.

## Setup

```bash
npm install
npm run dev
```

Create `.env.local`

```env
NEXT_PUBLIC_SITE_URL=http://localhost:3000
NEXT_PUBLIC_CASHFREE_MODE=sandbox
CASHFREE_CLIENT_ID=your_client_id
CASHFREE_CLIENT_SECRET=your_client_secret
```

Deploy to Vercel and connect vidyavikasacademy.in
